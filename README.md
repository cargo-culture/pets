# Pets

## Bleu

A derpy chibi Bernese Mountain Dog for Codex.

[Download Bleu.zip](https://raw.githubusercontent.com/cargo-culture/pets/main/release/animals/bleu/Bleu.zip) (about 2.2 MB), then extract it.

- **Windows:** Double-click `Install-Bleu.cmd` in the extracted folder.
- **macOS:** Double-click `Install Bleu.command`. If it will not open, type `bash ` in Terminal, drag the command file into Terminal, and press Return.

Restart Codex, then select Bleu in the pet picker. Requires a client with custom pets support.

Installs offline into `~/.codex/pets/bleu`, or `$CODEX_HOME/pets/bleu` when configured. Running again replaces Bleu's two files.

[Details and manual installation](release/animals/bleu/README.md).
